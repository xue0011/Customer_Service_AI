# 退货政策参考

## 退货政策摘要

### 7天无理由退货
- **条件**：自签收之日起7天内，商品完好、吊牌标签完整、未使用、不影响二次销售
- **例外**：定制商品、生鲜食品、内衣裤袜、已拆封的数码产品、一次性卫生用品
- **运费**：买家承担退货运费
- **退款时间**：收到退货后3-5个工作日

### 质量问题退货
- **条件**：商品存在质量问题（破损、瑕疵、功能故障等）
- **运费**：卖家承担全部运费
- **退款时间**：收到退货后1-3个工作日
- **补偿**：可酌情补偿优惠券（最高50元）

### 错发/漏发
- **处理**：核实后补发或退款
- **运费**：卖家承担
- **退款时间**：确认后1-2个工作日

### 物流损坏
- **要求**：需提供开箱视频或破损照片
- **运费**：卖家承担
- **注意**：保留快递面单和包装，以便向快递公司索赔

## 200元阈值规则

| 订单金额 | 处理方式 | 说明 |
|----------|----------|------|
| < ¥200 | 自动判断 | 系统自动检查退货条件，通过则直接批准，不通过则拒绝并说明原因 |
| >= ¥200 | 人工审核 | 生成工单提交人工审核，预计24小时内回复 |

## 退货流程
1. 顾客在订单页面申请退货退款
2. 选择退货原因并提交
3. 审核通过后，将商品寄回指定地址
4. 仓库收到退货后验货（1-2个工作日）
5. 验货通过后发起退款（3-5个工作日到账）

## 常见退货场景处理

| 场景 | 处理方式 |
|------|----------|
| 尺码不合适 | 符合7天无理由，可退 |
| 颜色不喜欢 | 符合7天无理由，可退 |
| 质量有问题 | 卖家承担运费退货 |
| 与描述不符 | 核实后卖家承担运费退货 |
| 不想要了 | 符合7天无理由，可退（买家承担运费） |
| 超过7天 | 不符合条件，可提供优惠券补偿 |
| 已拆封电子产品 | 不符合条件（除非质量问题） |
| 定制商品 | 不支持退货 |
