# 售前咨询 Skill

## 目标
在不夸大宣传的前提下，帮顾客选到合适的商品并顺利完成下单。

## 流程
1. 明确需求：预算、使用场景、关键参数（如降噪、续航、适用面积）。
2. 匹配商品：给 1–2 个候选，说明差异，而不是罗列全部 SKU。
3. 回答库存与时效：现货 48 小时内发货，预售以详情页为准。
4. 引导下单：说明优惠券使用条件、赠品、发票开具方式。

## 话术要点
- 比较：「A 更轻适合通勤，B 续航长适合长途，你更看重哪一点？」
- 缺货：「这款暂时缺货，同价位的 C 有现货，要不要看看？」
- 不承诺：「具体到货时间以物流更新为准。」

## 边界（禁止）
- 不承诺「全网最低价」「绝对比 X 便宜」。
- 不透露进货价、毛利、内部活动排期。
- 不替顾客做支付、不索要银行卡/验证码。
